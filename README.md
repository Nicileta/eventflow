# 📅 EventFlow — Manager de Evenimente

EventFlow este o aplicație web modernă pentru gestionarea evenimentelor, construită folosind HTML, CSS și JavaScript (vanilla). Aplicația permite organizarea eficientă a activităților zilnice prin adăugare, filtrare, sortare și urmărirea evenimentelor.



## ✨ Funcționalități

* ➕ Adăugare evenimente (titlu, categorie, prioritate, dată, oră, locație, status, descriere)
* ✏️ Editare și actualizare evenimente
* 🗑️ Ștergere evenimente
* ⭐ Marcarea evenimentelor favorite
* 🔍 Căutare în timp real (titlu, locație, descriere)
* 🎯 Filtrare după:

  * categorie
  * status
  * prioritate
* ↕️ Sortare după:

  * dată
  * titlu
  * prioritate
  * categorie
  * status
* 📄 Paginare (5 / 10 / 20 / 50 per pagină)
* 📊 Statistici dinamice:

  * total evenimente
  * favorite
  * finalizate
  * urgente
* ⏱️ Countdown până la următorul eveniment
* ⏳ Timer sesiune activă
* 🌙 Mod Dark / Light
* 💾 Salvare automată în LocalStorage
* 📤 Export evenimente în format TXT



## 🧠 Tehnologii utilizate

* HTML5
* CSS3 (Custom Properties, responsive design)
* JavaScript (ES6+)
* LocalStorage API



## 🚀 Cum rulezi proiectul

1. Clonează repository-ul:

git clone https://github.com/Nicileta/eventflow.git

2. Deschide folderul proiectului

3. Rulează aplicația:
   deschide `index.html` în browser


## 💡 Cum funcționează

* Datele sunt salvate local în browser folosind `localStorage`
* Nu este necesar backend sau instalare
* Aplicația este complet client-side
